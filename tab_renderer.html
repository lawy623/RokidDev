Editor Reference

Selection

Click note number
Select that note.
Click technique mark
Select the spanner (bend, vibrato, slide, tie, etc.).
Click empty measure area
Select the measure for insertion.
Set Target / Clear Target
Set or clear a range endpoint for beam-group, HP, or technique spanning multiple notes.

File Actions

Save JSON
Write the current in-memory score back to the loaded data/music/*.json file via the dev server.
Download
Export the current score as a downloaded JSON file.
Undo
Restore the previous score snapshot (up to 80 levels).

Pitch & Rhythm

String Up / Down
Move the selected note to a higher or lower string (1–6).
Fret − / +
Decrement or increment the selected note's fret number (0–24).
Duration
Set the selected event's note duration (whole through 64th).
Dots
Set the selected event's dot count (0, 1, or 2).

Mark

Tied
Toggle tied status (15) and auto-create a tie from the previous matching note.
A.H.
Toggle an artificial-harmonic note, rendered with angle brackets such as <19>.
Ghost
Toggle ghost-note display (15). Ghost notes are silent during playback.
Ring
Toggle ring status — draws a circle around the fret number and auto-fills the remaining measure duration.
Dead
Toggle dead-note display (X) with normal duration — a timed muted strike.
Mute (Insert)
Insert a decorative mute X that sits at the chosen tick position without consuming measure time. Does not shift other notes. Plays as a very short pluck.
Staccato
Toggle a staccato articulation dot above the event.
Delete
Delete the selected note. If the event has no notes left, the event and its spanners are also removed.

Measure & Insert

Add / Del
Insert or delete a measure at the selected position.
Dup / Dup End
Duplicate the selected measure. Dup inserts the copy right after it; Dup End appends the copy to the very end of the score.
Widen / Narrow
Toggle the selected measure between 1-slot (auto) and 2-slot (wide). Wide measures have more horizontal space and slower playhead speed.
After
Insert a new note event after the selected event (or at the selected measure insertion point).
Before
Insert a new note event before the selected event.
Chord
Add another note to the selected event at the same tick (build a chord).
Insert selectors
Default string, fret, and status for the next Add After or Add Chord.

Beam & HP

Group Beam
Assign a new beamGroup to all note events between the anchor and the range target in the same measure.
Beam Next
Group the selected note event with the next note event in the same measure.
Add Prev
Group the selected note event with the previous note event in the same measure.
Split
Cleave the beamGroup after the selected event: the selection and everything before it keep the old group, events after get a new group.
Dup
Duplicate the entire beam group (all its note events) and append the copy right after the group. The duplicated notes share a new beam group and keep the same strings, frets, durations, and effects.
Ungroup
Remove the beamGroup from every event that belongs to it — the notes remain but are no longer beamed together.
Tuplet
Apply a tuplet ratio to all events in the selected beam group. 3:2 = triplet (3 in time of 2), 2:3 = duplet, etc. Plays back with corrected timing and draws a bracket below the beam.
H
Add a connected hammer-on from the selected note to the next/target note.
P
Add a connected pull-off from the selected note to the next/target note.
H In
Add a single-ended hammer-on into the selected note (no source). Use the kind selector and optional endpoint fret to adjust.
P Out
Add a single-ended pull-off out of the selected note (no target). Use the kind selector and optional endpoint fret to adjust.
HP
Add a three-note hammer-on then pull-off chain.

Target & Line Techniques

Set Target / Clear Target
Set or clear a range endpoint for techniques spanning multiple notes.
Tie
Connect the selected note to the next matching string/fret note with a tie curve (below the fret numbers).
Slur
Connect the selected note to the next note with a generic slur curve (below the fret numbers).
Slide
Connect the selected note to the target/next note with a diagonal slide line and "sl." label.
Slide In
Add a single-ended slide into the selected note. Set an optional endpoint fret to show the starting pitch as a small number.
Slide Out
Add a single-ended slide out of the selected note. Set an optional endpoint fret to show the ending pitch as a small number.

Sound, Bend & Apply Params

Vibrato
Add a wavy vibrato line above the selected note, extending to the target/next note or to measure end.
Let Ring
Add a let-ring range from the selected event to the target/next event.
P.M.
Add a palm-mute range (dashed line) from the selected event to the target/next event.
Trill
Add a trill ("tr") from the selected note to the next note.
Del Tech
Delete the selected spanner.
N.H. / A.H. / P.H.
Toggle natural, artificial, or pinch harmonic on the selected note. Click again to remove. Renders a label above the note and plays one octave higher.
Bend Up
Add a bend-up curve to the selected note.
Bend Up Down
Add an up-then-down bend curve from the selected note to the target/next note, skipping tied/ghost notes.
Bend Vib
Bend up to the target pitch, then draw vibrato at the peak.
Vibrato width
Narrow / Normal / Wide — controls the amplitude of the vibrato wave.
Slide direction
Up / Down — for single-ended slides.
Kind
Controls the spanner shape: Shift (connected), In (into the note), Out (out of the note). Applies to both slide and H/P spanners.
Bend amount
Control the bend curve alter value: 1/4, 1/2, full, 1.5, or 2.
Label
Custom label text shown above the spanner. Leave empty for auto-generated label.
Apply Params
Apply all the above settings to the currently selected spanner.
